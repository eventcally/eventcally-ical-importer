# Eventcally ical importer

An [EventCally](https://github.com/eventcally/eventcally) app that imports iCal feeds into
the calendars of the organizations that installed it.

Flask + SQLAlchemy + Celery backend, Vue 3 frontend (`frontend/`) fed by a BFF (`/bff`);
Python dependencies are managed with [uv](https://docs.astral.sh/uv/).
